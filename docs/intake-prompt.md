# 初回ダンプ用プロンプト

Claude Code を起動した直後、以下をそのまま最初のメッセージとして貼る。
Claude が質問しながら、頭の中・既存資料にあるプロジェクト情報を `workspace/` に構造化して書き出してくれる。

---

```
これから担当プロジェクトの情報をあなたに渡して、この PM-OS に構造化して取り込んでもらいたい。

進め方:
1. まず私に、各プロジェクトについて順番にヒアリングして。一度に全部聞かず、1プロジェクトずつ。聞くのは「目的・ゴール / 現状 / 主要タスク / 関係者 / 直近で決めた/決める必要のあること / リスク」あたり。私が即答できない項目は推測で埋めず空欄のままにして、後で埋める印を残して。
2. ヒアリングが済んだら、templates/ のひな形に従って:
   - workspace/projects/ にプロジェクトノートを作成
   - 既に下した重要な意思決定があれば workspace/decisions/ に意思決定ノートを作成
   - 主要な関係者を workspace/people/ に作成
   - ノート間を [[リンク]] で結ぶ
3. 最後に workspace/_active-context.md を更新して、現在の優先事項・進行中の作業・次のアクションをまとめて。

まずは「いくつプロジェクトを抱えているか」と「一番優先度が高いのはどれか」から聞いて。
```

---

## 既存資料がある場合

ドキュメント・議事録・チャットログ等が手元にあるなら、それを `workspace/inbox/` に置く（コピペでも、ファイルを入れてもいい）。そのうえで上のプロンプトに一行足す:

```
workspace/inbox/ に既存資料を置いてある。ヒアリングの前にそれを読んで、分かる範囲は埋めた状態で確認に来て。
```
