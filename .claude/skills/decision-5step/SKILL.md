# 5ステップ意思決定（Dalio式）

Ray Dalioの『Principles』に基づく汎用意思決定フレームワーク。**目標と問題の分離、問題と根本原因の分離**が核心。

## いつ使うか

- 優先順位決め（その日 / その週の方針）
- 週次振り返り（同じ問題が繰り返されていないか）
- 行き詰まり時の打破
- 「なぜうまくいかないか」の分析

使わない場面:
- 単純な事実確認・作業指示
- 既に根本原因が明らかな問題

## 5ステップ

### 1. 目標を知る（Goals）
- 本当に達成したいことは何か？
- 複数の目標は優先順位をつけられているか？
- 目標は**具体的で測定可能**か？

### 2. 問題を許容しない（Problems）
- 目標達成を妨げている問題は何か？
- 見て見ぬふりをしていた問題はないか？
- 「仕方ない」で処理していないか？

### 3. 根本原因を診断する（Diagnose）
- 表面的症状と根本原因を分離
- 「なぜ？」を最低3回繰り返す
- **自分の弱点・習慣・チームの構造**に原因がないか

### 4. 計画を設計する（Design）
- 根本原因に効く具体的アクションは？
- 実行可能な最小単位まで分解
- いつ、誰が、何を、どれくらい？

### 5. 実行する（Do）
- 計画をタスク化
- 結果を測定
- 1で定めた目標に照らして評価 → ループ

## 出力テンプレート

```
## 1. 目標
- <具体的で測定可能な目標>

## 2. 問題
- <目標を妨げている問題1>
- <問題2>

## 3. 根本原因
- 問題1 → なぜ？ → なぜ？ → なぜ？ → <根本原因>

## 4. 計画
- [ ] <最小単位のアクション1>（担当 / 期限）
- [ ] <アクション2>

## 5. 実行
- 測定方法: ...
- 次のレビュー: <日付>
```

## 週次レビューの特別プロンプト

週次振り返りでは以下を必ず問う:
- **「先週と同じ種類の問題を繰り返していないか？」**
- 繰り返している場合、Step 3（根本原因）が不十分 → 再診断

レビュー結果は `workspace/_active-context.md` の次アクションに反映する。
